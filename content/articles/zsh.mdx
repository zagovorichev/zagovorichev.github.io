## Installation

1. `sudo apt install zsh` Install Zsh
2. `sh -c "$(curl -fsSL https://raw.github.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"` Install OhMyZsh
3. `chsh -s $(which zsh)` Set Zsh as a default terminal
4. [Powerlevel10k](https://github.com/romkatv/powerlevel10k) theme

## Plugins

Put them to the `~/.zshrc`:

```bash
plugins=(git sublime wd sudo copyfile copypath composer command-not-found zsh-autosuggestions aliases alias-finder docker-compose per-directory-history)
```

- [git](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/git)<br/> <Muted>`g` git <br/> `ga` git add<br/> `gc` git commit -v<br/> `gpristine` git reset --hard && git clean -dffx<br/> `gcd` git checkout $(git\_develop\_branch)<br/> `gd` git diff <br/> `gf` git fetch <br/> `gl` git pull <br/> `grv` git remote -v <br/> `current_branch` Return the name of the current branch <br/> `git_current_user_name`Returns the *user.name* config value<br/> `git_current_user_email` Returns the *user.email* config value</Muted>
- [sublime](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/sublime)<br/> <Muted>`st` opens Sublime Text. If passed a file or directory, Sublime Text will open it.<br/> `stt` open Sublime Text on the current directory.<br/> `sst` if sudo is available, sst will open Sublime Text with root permissions, so that you can modify any file or directory that you pass it. Useful to edit system files.</Muted>
- [wd](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/wd)<br/> <Muted>`wd add foo` Add warp point to current working directory (--force to rewrite). <br/> `wd foo` From any directory, warp to foo. <br/> `wd rm foo` Remove warp point. <br/> `wd list` List all warp points (stored in ~/.warprc by default). <br/> `wd path foo` Show path of given warp point. <br/> `wd show` List warp points to current directory. <br/> `wd clean` Remove warp points to non-existent directories. </Muted>
- [sudo](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/sudo)<br/> <Muted>By pressing the `esc` key twice, you will have the same command with `sudo`</Muted>
- [copyfile](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/copyfile)<br/> <Muted>Puts the contents of a file in your system clipboard so you can paste it anywhere.</Muted>
- [copypath](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/copypath)<br/> <Muted>copies the absolute path of the current directory.</Muted>
- [composer](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/composer)<br/> <Muted>`c` composer<br/> `cdu` composer dump-autoload<br/> `ci` composer install<br/> `cr` composer require<br/> `crm` composer remove<br/> `csu` composer self-update<br/> `cu` composer update</Muted>
- [command-not-found](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/command-not-found)<br/> <Muted>This plugin uses the command-not-found package for zsh to provide suggested packages to be installed if a command cannot be found.</Muted>
- [zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions)<br/> <Muted>It suggests commands as you type based on history and completions. <br/> **Installation** <br/> `git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions` <br/> `exec zsh` </Muted>
- [aliases](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/aliases) <br/> <Muted>`acs` show all aliases by group.<br/> `acs` \<keyword\>: filter aliases by \<keyword\> and highlight.</Muted>
- [alias-finder](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/alias-finder) <br/> <Muted>This plugin searches the defined aliases and outputs any that match the command inputted. This makes learning new aliases easier.</Muted>
- [docker-compose](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/docker-compose) <br/><Muted>`dco` docker-compose <br/> `dcb` docker-compose build <br/> `dce` docker-compose exec <br/> `dcrestart` docker-compose restart <br/> `dcr` docker-compose run <br/> `dcstop` docker-compose stop <br/> `dcup` docker-compose up <br/> `dcupb` docker-compose up --build <br/> `dcupd` docker-compose up -d <br/> `dcdn` docker-compose down <br/> `dclf` docker-compose logs -f </Muted>
- [per-directory-history](https://github.com/ohmyzsh/ohmyzsh/tree/master/plugins/per-directory-history) <br/><Muted>This plugin adds per-directory history for zsh, as well as a global history, and the ability to toggle between them with a keyboard shortcut Ctrl + G.</Muted>

Full list of plugins is here: [Plugins →](https://github.com/ohmyzsh/ohmyzsh/wiki/Plugins)

## Hot keys and Shortcuts

Add to `~/.zshrc`.

**Windows**

```bash
alias ofd="/mnt/c/Windows/explorer.exe" # ofd . - open this dir in explorer
alias subl="/mnt/c/Program\ Files/Sublime\ Text/subl.exe" # subl file
```

**Project**

```bash
alias rtraf="~/sandbox/dockerizer && docker-compose up -d" # to run traefik
alias straf="~/sandbox/dockerizer && docker-compose down" # to stop traefik
alias phpstan='docker run -v $PWD:/app --rm ghcr.io/phpstan/phpstan' # to run phpstan
alias php81composer='docker run -v $PWD:/app --rm php81container composer update' # to run composer under php8 (check img in docker)
alias php81test='docker run -v $PWD:/app --rm php81container ./vendor/bin/phpunit tests'
alias php74composer='docker run -v $PWD:/app --rm php74container composer update'
alias php74test='docker run -v $PWD:/app --rm php74container ./vendor/bin/phpunit tests'
```
