When developing more than one monolithic project, there is a problem with the use of ports. For example 80 port for application1 cannot be used for application2, so you have to forward the ports to http://application1.loc:80 http://application2.loc:81 and for https it gets even more complicated. How to design an environment to support http://application1.loc, http://application2.loc and https://application1/2.loc?

## Dockerizer

[https://github.com/zagovorichev/dockerizer](https://github.com/zagovorichev/dockerizer)

Dockerizer it is an example of how traefik can be configured. Plus it has WhoAmI service to see network info and Portainer - to see all docker containers/volumes, etc.

### How to install Dockerizer

```bash
git clone https://github.com/zagovorichev/dockerizer.git
docker network create traefik-public
docker-compose up -d
```

And check that [WhoAmI](http://whoami.docker.localhost) works.

### Secure protocol HTTPS from the box

> If you want to do it for Windows with WSL2 then there are some extra steps marked with ⊞. If not - just skip them.

- ⊞ Install Chocolatey. <br/> Powershell command: `Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))`
- ⊞ Install mkcert for Windows from Powershell: `choco install mkcert`
- ⊞ Find and save path to CertRoot: `mkcert -CAROOT`
- Install mkcert for Linux: <br/> `sudo apt install libnss3-tools` <br/> `curl -JLO "https://dl.filippo.io/mkcert/latest?for=linux/amd64"` <br/> `sudo cp mkcert-v*-linux-amd64 /usr/local/bin/mkcert` <br/> <Muted>or check preferable for you way to install mkcert: [https://github.com/FiloSottile/mkcert](https://github.com/FiloSottile/mkcert)</Muted>
- ⊞ Copy all root certificates from WSL 2 to Windows
- Goto **dockerizer/docker/traefik/certs** <br/> And generate new certificates: <br/> `mkcert "*.docker.localhost" "traefik.docker" "*.docker"`

## Windows WSL2 + Windows Docker Configuration

1. GoTo Microsoft Store → search for Ubuntu 22 LTS → Install → Run

   > Possible issue: If Windows Subsystem for Linux is not installed.<br/> Fix: Start → Settings → Update & Security → For developers: Turn Developer mode to **ON**<br/> Then restart WSL installation:
   >
   > - Windows Key + R
   > - type: optionalfeatures.exe
   > - Check Windows Subsystem for Linux
   > - It will restart windows at the end
   >
   > After that you can open *Start → Ubuntu 22 LTS* and that will finish installation.

   > In cmd : `wsl -l -v` should show v2 or try to do `wsl --set-default-version 2`

   > And if you have already installed Linux distributive with WSL v1 `wsl --set-version Ubuntu-22.04 2`
2. (Optional) Check that Windows Terminal installed. Start → wt.

   > If it is not installed<br/> Start → Store → Search for Windows Terminal → install

   > In the WT: Ctrl + , → Default Ubuntu 22
3. GoTo [docker.com](https://docker.com) → Download Docker Desktop <br/> <Muted>After that WSL 2 has docker installed or check Docker Desktop with WSL 2 instructions: [docs.docker.com/go/wsl2](https://docs.docker.com/go/wsl2) <br/> `docker ps` if doesn't work: `sudo usermod -aG docker YOUR_USERNAME` and restart terminal.</Muted>
